# hollow-services: Blender source (ROADMAP Z-D6 "Blender everything", 2026-11-03)

Blossom Hollow's service buildings: clinic, well, school, onsenHall, waterTower, bulletinBoard, stashChest. Built by an Opus agent by script (`build_hollow-services.py --piece <name|all>`, deterministic); reviewed by Claude in the game. The working
folder `tools/blender/work/codex/hollow-services/` (renders, .blend files, kit dumps) is git-ignored. Brief: `brief.md`. GLBs in
`public/models/`. Game hook: catalog.js `glb` (well/school/stashChest glbKeep ['anim'], onsen/waterTower ['jet']).
